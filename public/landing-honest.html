How it works

Two SDK calls wrap every agent.

authorize() before the work, debit() after success. The pattern never changes - copy it once, reuse it across your whole suite.

1 · authorize()

Plan gate and balance check return under 50ms with a full decision package - never a blind 402 wall.

2 · Run your agent

Any HTTP-speaking workload. AgentMint is agnostic to whatever runs in the middle.

3 · debit()

Atomic Postgres transaction with advisory lock. Idempotent by resource_id. Balance never goes negative.

route.ts 
// Two plain HTTP calls. There is no SDK package yet -
// a thin typed wrapper is on the roadmap.

const auth = await fetch(`${'$'}{BASE}/authorize`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${'$'}{KEY}`, 'content-type': 'application/json' },
  body: JSON.stringify({ workspaceId, product: 'your_agent', action: 'do_thing', cost: 25 }),
}).then(r => r.json());

if (!auth.allowed) return Response.json(auth, { status: 402 });

// whatever your agent actually does
const result = await runYourAgent(req.body);

await fetch(`${'$'}{BASE}/debit`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${'$'}{KEY}`, 'content-type': 'application/json' },
  body: JSON.stringify({
    workspaceId, product: 'your_agent', action: 'do_thing', cost: 25,
    resourceId: result.id,            // authoritative idempotency key
  }),
});

Plan gating

Every 402 is an upgrade event.

FAQ

Answers before you ask.

Still unsure? Email the team.

I am a solo dev. Is this overkill for me?+

No. Signup is 30 seconds, you get the same SDK, the same dashboard, the same Stripe Connect path. There is no minimum scale. Trial credits are free.

Do my agents need a specific stack?+

No. There is no SDK package yet - integration is two plain HTTP POST calls (authorize + debit). Anything that speaks HTTPS - Python, Go, Rust, edge functions, n8n - can bill through AgentMint. A thin typed SDK wrapper is on the roadmap once the wire format is locked.

How does the money actually get to my bank?+

Honest answer: not directly yet. Stripe Connect is on the roadmap. For the first cohort, settlement is offline - you can pilot the credit ledger + plan gating + enriched 402 contract end-to-end, but cash collection happens outside AgentMint. The design is: your customers pay through your Stripe account via Connect, AgentMint takes a small platform fee, and Stripe pays out to your bank on your schedule. We never hold the money. That ships next.

How do you price AgentMint?+

See the pricing section above for the full picture. Summary: first cohort = $0, post-pilot = flat platform fee + capped percentage of payment volume processed.

Can credit costs change without a deploy?+

Yes. Costs live in the registry table. Move an action from 50 to 40 credits and it ships on the next request.

What about India, INR and GST?+

USD on Stripe today. INR, UPI and GST-compliant invoicing is on the roadmap - already on the schema.
